# 🛍️ دكّانة: متجر أونلاين لأي محل في دقيقتين، والطلبات توصل على واتساب

صاحب المحل يسجل، يضيف منتجاته بالصور والأسعار، وياخد لينك واحد (`/s/اسم-المحل`) يبعته لزباينه.
الزبون يفتح اللينك من موبايله، يختار، ويضغط "ابعت الطلب على واتساب". الطلب يوصل لصاحب المحل مكتوب ومحسوب (المنتجات والكميات والتوصيل والإجمالي والعنوان)، ويتسجل في لوحة التحكم.

## نموذج الربح

| الباقة | السعر | المميزات |
|---|---|---|
| مجانية | 0 | لحد 10 منتجات، وعلامة "دكّانة" في آخر المتجر |
| احترافية | 99 ج.م/شهر أو 990 ج.م/سنة | منتجات من غير حد، من غير علامة، وإحصائيات المبيعات |

- كل متجر جديد بياخد **14 يوم احترافية هدية**. لما تخلص، المنتجات اللي فوق الـ 10 بتختفي من المتجر، وده بيشجع على الاشتراك.
- **الدفع**: فودافون كاش أو إنستاباي. التاجر يحوّل ويكتب رقم العملية، وانت تضغط "قبول" من لوحة الإدارة.
- **الانتشار الذاتي**:
  - كل متجر مجاني فيه زرار "اعمل متجر زي ده مجاناً"، فكل زبون بيشوفه بيبقى عميل محتمل.
  - كل تاجر عنده لينك دعوة: لما تاجر تاني يسجل منه ويدفع، صاحب اللينك ياخد شهر مجاني.

### حسبة المليون بصراحة
مليون جنيه في السنة بسعر 99 جنيه في الشهر يعني محتاج **حوالي 850 تاجر دافع شغالين طول السنة**.
لو 3% لـ 5% من المتاجر المجانية بيدفعوا (ده معدل معتاد لبرامج الاشتراك)، يبقى محتاج من 17,000 لـ 28,000 متجر مسجل.
ده رقم ممكن في سوق فيه ملايين المحلات، بس مش هيحصل لوحده. أول 50 لـ 100 تاجر لازم توصلهم بنفسك (شوف "خطة أول 100 عميل" تحت). بعد كده التسويق بالدعوات والعلامة على المتاجر بيكمّل.

## التشغيل على جهازك

محتاج Node.js إصدار 22.13 أو أحدث.

```bash
cd dukkana
npm install
npm run seed-demo        # يعمل متجر تجريبي على /s/demo
ADMIN_PASSWORD=secret VODAFONE_CASH_NUMBER=01012345678 npm start
```
بعدها افتح http://localhost:3000. لوحة الإدارة على http://localhost:3000/admin.

الاختبارات: `npm test` (31 اختبار، كلهم ناجحين).

## النشر على الإنترنت

البرنامج سيرفر Node واحد، والبيانات في ملف SQLite جوه فولدر `DATA_DIR`.
**مهم جداً:** لازم الفولدر ده يكون على **قرص دائم (persistent volume)**، وإلا البيانات هتضيع مع كل إعادة تشغيل.

أسهل طريقتين:
1. **سيرفر VPS** (أي شركة بتأجّر سيرفرات صغيرة، بحوالي 5 دولار في الشهر): نزّل Docker، وبعدين:
   ```bash
   docker build -t dukkana .
   docker run -d --restart=always -p 80:3000 -v /srv/dukkana:/data --env-file .env dukkana
   ```
   حط قدامه Cloudflare أو Caddy عشان HTTPS.
2. **Railway أو Render أو Fly.io**: اربط الريبو، اختار الـ Dockerfile، وضيف Volume متركّب على `/data`.

### الإعدادات (Environment variables)
شوف ملف `.env.example`. أهمها:
- `BASE_URL`: الدومين بتاعك، مثلاً `https://dukkana.com`. **لازم** تتظبط في السيرفر الحقيقي.
- `ADMIN_PASSWORD`: كلمة سر طويلة لوحة الإدارة. لو فاضية، لوحة الإدارة بتبقى مقفولة.
- `VODAFONE_CASH_NUMBER` و `INSTAPAY_ADDRESS`: الأماكن اللي التجار هيحوّلوا عليها.
- `SUPPORT_WHATSAPP`: رقمك بالصيغة الدولية (`2010...`) عشان الدعم و"نسيت كلمة السر".
- `TRUST_PROXY=1`: لو السيرفر ورا Cloudflare أو Nginx أو منصة استضافة.

### النسخ الاحتياطي
كل البيانات في `DATA_DIR` (ملف `dukkana.db` وفولدر `uploads`). خد منهم نسخة كل يوم. مثلاً:
`sqlite3 /srv/dukkana/dukkana.db ".backup /backups/dukkana-$(date +%F).db"`

## شغلك اليومي (حوالي 5 دقايق)
1. افتح `/admin`.
2. لكل دفع مستني مراجعة: اتأكد من تطبيق فودافون كاش أو البنك إن المبلغ ورقم العملية وصلوك فعلاً، وبعدين اضغط **قبول وتفعيل**. لو مش لاقي التحويل، اضغط **رفض**.
3. لو تاجر نسي كلمة السر، دوّر عليه واضغط **كلمة سر جديدة** وابعتهاله على واتساب.

## خطة أول 100 عميل (من غير ميزانية)
1. اعمل متجر حقيقي لـ 5 محلات تعرفهم بنفسك، واملالهم المنتجات انت ببلاش.
2. انزل اعرضه على المحلات اللي حواليك. الجملة اللي بتبيع: "الزبون يطلب لوحده، والطلب يوصلك على واتساب محسوب".
3. انشر في جروبات فيسبوك بتاعة البيزنس المنزلي والحلويات والملابس. الفئة دي بتبيع على واتساب أصلاً ومحتاجة كتالوج.
4. صوّر فيديو قصير (30 ثانية) لمتجر بيستقبل طلب، وانشره ريلز وتيك توك.
5. فكّر كل تاجر يشارك لينك الدعوة بتاعه (الشهر المجاني بيحفّز).

## الأمان (اتعمل واتختبر)
- كلمات السر متخزنة بـ scrypt، والجلسات بتوكنز عشوائية متخزنة كـ hash.
- حماية CSRF على كل الفورمز، وحماية XSS (كل النصوص بتتعمل escape، ومعاها Content-Security-Policy).
- الأسعار والإجمالي بيتحسبوا على السيرفر دايماً، فالزبون مايقدرش يغيّر السعر.
- الصور بيتأكد إنها صور حقيقية (JPG/PNG/WEBP)، وأقصى حجم 2 ميجا.
- فيه حد لعدد المحاولات على الدخول والتسجيل والطلبات ولوحة الإدارة.
- كل تاجر بيشوف ويعدّل بياناته هو بس.

## هيكل الكود
```
server.js            تشغيل السيرفر
src/app.js           الإعدادات العامة، الأمان، رفع الصور
src/services.js      قواعد البيزنس (الباقات، الدفع، الدعوات، الإحصائيات)
src/routes/          الصفحات: العامة، لوحة التاجر، الإدارة
src/views/           قوالب HTML (عربي، RTL، موبايل أولاً)
public/              CSS، وسلة المشتريات (store.js)، والأيقونة
test/                الاختبارات
```
